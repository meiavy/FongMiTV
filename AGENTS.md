# Agent Instructions

## Build Commands

```bash
./gradlew assemble            # Debug build (all variants)
./gradlew assembleLeanbackArm64_v8aRelease  # Leanback TV APK (arm64)
./gradlew assembleMobileArm64_v8aRelease    # Mobile APK (arm64)
./gradlew clean               # Clean build artifacts
```

Release APKs are copied to `Release/apk/` after a successful `assemble.*Release` build.

## Signing (Release Builds)

Release builds require `local.properties` in the project root:

```
storeFile=/path/to/keystore.jks
keyAlias=your_alias
storePassword=your_password
keyPassword=your_password
```

Without this file, `assembleRelease` will fail.

## Project Structure

```
app/              Main application (453 Java files)
  src/main/       Shared code, assets, resources
  src/leanback/   TV UI (HomeActivity, remote-focused)
  src/mobile/     Mobile UI (HomeActivity, gesture-focused)
catvod/           Spider abstraction layer (namespace: com.github.catvod.crawler)
chaquo/           Python 3.10 engine via Chaquopy (ABI-split: arm64_v8a, armeabi_v7a)
quickjs/          QuickJS JavaScript engine wrapper
forcetech/        ForceTech live engine
hook/             PackageManager stub — fakes package signatures at runtime
jianpian/         Jianpian link resolver
thunder/          Thunder download support
tvbus/            TVBus live streaming engine
zlive/            ZLive streaming support
```

## Key Entry Points

- **App**: `com.fongmi.android.tv.App` (Application class)
- **TV Home**: `com.fongmi.android.tv.ui.activity.HomeActivity` (leanback)
- **Mobile Home**: `com.fongmi.android.tv.ui.activity.HomeActivity` (mobile)
- **PlaybackService**: `com.fongmi.android.tv.service.PlaybackService` (Media3 MediaLibraryService)
- **Remote Server**: `com.fongmi.android.tv.server.Server` — NanoHTTPD on port 9978–9998

## Spider / Crawler System

Three spider runtimes, selected by URL pattern in config:

| Pattern | Loader | Runtime |
|---------|--------|---------|
| `.js` | `JsLoader` | QuickJS |
| `.py` | `PyLoader` | Chaquopy (Python 3.10) |
| `csp_` prefix | `JarLoader` | DexClassLoader (Java JAR) |

Spider interface: `com.github.catvod.crawler.Spider` (catvod module)
Config: `com.fongmi.android.tv.api.config.VodConfig`, `LiveConfig`

## Notable Config / Code Locations

- **Room schema export**: `app/schemas/com.fongmi.android.tv.db.AppDatabase`
- **EventBus index**: `com.fongmi.android.tv.event.EventIndex` (generated by annotation processor)
- **NanoHTTPD server**: `Server.java` binds port 9978–9998
- **Hook (signature spoofing)**: `com.fongmi.hook.Hook` (extends PackageManager), activated via `App.setHook()`
- **DanmakuFlameMaster**:弹幕同步播放; DanmakuApi.java handles injection
- **DLNA**: DMC (mobile cast) in `dlna/` package, DMR (TV renderer) in `service.DLNARendererService`

## Dependency Management

- Uses Gradle version catalog: `gradle/libs.versions.toml`
- `settings.gradle` uses `FAIL_ON_PROJECT_REPOS` mode — all repos are centralized
- Local AAR libs go in `app/libs/*.aar` (pre-built: forcetech, hook, jianpian, thunder, tvbus)
- Python pip deps: `chaquo/requirements.txt` (lxml, ujson, pyquery, requests, cachetools, pycryptodome, beautifulsoup4)

## No Test Suite

This project has **no unit tests or instrumented tests** anywhere in the source tree. Do not look for or attempt to run a test command.

## Build Variants

Flavor matrix: 2 (mode) × 2 (ABI) = 4 variants per `buildType`:
- `leanback-arm64_v8a`, `leanback-armeabi_v7a`
- `mobile-arm64_v8a`, `mobile-armeabi_v7a`

APK output naming: `{mode}-{abi}.apk` (e.g., `leanback-arm64_v8a.apk`)

## Important Notes

- **minSdk=24** (Android 7.0), **targetSdk=37**, **compileSdk=37**
- **Java 21** is used for both source and target compatibility
- `coreLibraryDesugaringEnabled=true` — Java 8+ APIs are desugared
- Chaquopy Python is ABI-split; only `armeabi-v7a` and `arm64-v8a` are supported (no universal)
- The `hook` module is loaded via `App.setHook()` only when TVBus extractor is active — it intercepts `PackageManager` calls to return fake package signatures for DRM license validation
- ProGuard rules: `app/proguard-rules.pro` + `app/proguard-rules-media.pro`
- Lint is configured to disable `UnsafeOptInUsageError` and `ExpiredTargetSdkVersion`
